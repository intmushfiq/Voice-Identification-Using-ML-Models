# Voice-Identification-Using-ML-Models
This is a project from my undergrad level-3 term-1 course of Digital Signal Processing. In this project we used KNN, SVM and Random Forest model to identify an user from voice data.
In the project the recorded audio is at first filtered and then the MFCC coefficients are taken. Datasets are made with the MFCC coefficients which is then used to train the models.
We recorded users name and id for the datasets.
Two ML models of the same category is trained by separate datasets (Name and ID) to ensure correct identification.
For identification user has to state his/her name and id separately.
